# Public access, rare-deal signup and search discovery

## Product behavior

The catalog is free to browse without an account or invite. Admin pages retain their own authorization. The default is public, and Vercel production PUBLIC_MODE is explicitly 1.

Visitors can join an email-only rare-deal launch list. The copy clearly states alerts are coming soon. Sending is deliberately deferred at the owner's request. The signup table is separate from the old invite waitlist; it records normalized email, UTC signup time, consent version and a hashed private removal token. Repeated signup does not rotate the original removal token. The returned link permits removal without an account. No email addresses or raw tokens enter public artifacts. The existing protected admin page displays the new list separately.

Before delivery launches: configure a sender, confirm ownership of each email, provide unsubscribe support in each message, and implement and validate the advertised rare-deal selection process. A large advertised discount alone is not a verified rare deal. This release makes no claim that delivery is active.

## Competitor observations — October 31, 2026

Google query inspected directly: `ski snowboard deals price comparison`. The observed results included sponsored shopping placements, an AI overview and organic links to Steep & Cheap and Sun & Ski Sports category pages, along with a community discussion about price tracking. This is one localized, signed-in search observation, not a ranking survey. Paid placements are distinct from organic search. We cannot infer why Google ranked a page from its placement alone.

The category-page advantage is actionable and supported by [Google's ecommerce navigation guidance](https://developers.google.com/search/docs/specialty/ecommerce/help-google-understand-your-ecommerce-site-structure): use crawlable links and useful page structure. [Google's URL guidance](https://developers.google.com/search/docs/specialty/ecommerce/designing-a-url-structure-for-ecommerce-sites) supports stable URLs and consistent canonicalization. [Faceted-navigation guidance](https://developers.google.com/search/blog/2024/12/crawling-december-faceted-nav) explains the crawl cost of uncontrolled filter combinations.

## Implemented search improvements

- Six stable `/gear/…` category pages, each with specific title, description, buying context, current server-rendered listings and real pagination links.
- Crawlable category links on the homepage and category pages.
- Canonical URLs, Open Graph metadata, social preview image and CollectionPage structured data. No fabricated product reviews or merchant claims.
- XML sitemap and robots.txt sitemap discovery. Search/filter permutations use noindex; stable category pagination has self-canonicals. Admin, invite, API and fragment routes remain outside intended indexing.
- A public alerts explanation page and privacy/signup details.

Search engines decide indexing and ranking; these changes improve discoverability and page clarity, not guarantee first-page placement. After domain activation, set SITE_URL to the new origin, redirect the old origin, submit the sitemap through Search Console and monitor indexing, impressions and queries. Avoid copying competitor text or publishing thin autogenerated product pages.
