The initial complete probe parsed 197 discounted products but accepted zero. Retained raw collections show exact IOC type `Welding` with tags `Equipment/Welding/MIG Welders`, `TIG Welders`, `Stick Welders`, `Multi Process`, or `Engine Drives`; these are currently unrecognized. Plasma machines use `Cutting` (some nondiscounted rows use Welding) plus `Equipment/Cutting & Plasma/Plasma Cutters`. A child `/Plasma Accessories` tag and `Parts & Accessories` type identify components. Two currently in-stock ESAB welders have feed discounts above 40% and reference above $200; they are candidates, not admitted deals.

Implement a narrow tools-catalog recognition rule bound to the observed IOC host, types and exact equipment taxonomy, after existing negative title/type/condition/component guards. Negative taxonomy descendants must win over parent machine tags; do not broadly accept any Welding/Cutting label or unscoped slash-tag. Preserve every price/stock/reference/variant field and existing retailer classification. Files: tools catalog classifier, meaningful tools classification regressions/fixtures and mirrored contract only. Source configuration remains inactive until fresh admission and independent review pass. Root separately inspects live shipping/package/reference and selected pages.
