## Changes

- Exact `Oscillating Tool Access` taxonomy is excluded before broad machine
  keywords. Primary `sanding pad(s)` and `nutsetter`/`nut setter` identities stay
  components regardless of compatibility wording or other machine nouns.
- Point Driver/Hacksaw/Nut Driver identities require an explicit electric,
  corded, cordless, pneumatic or powered descriptor on the primary identity.
  `Power Nut Driver` alone does not identify a motor. Power evidence is taken
  before for/compatible/fits clauses and existing included-accessory suffixes.

  `Cordless Drill Compatible Point Driver` cannot borrow Cordless from the drill.

  pads remain eligible; no generic exclusion of pad, driver or saw is added.
